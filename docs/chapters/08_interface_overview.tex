\chapter{Interface Overview}
\label{ch:interface_overview}

Duq features a high-density, vector-based interface designed for efficiency.

\section{Main Layout}
The interface is divided into five primary sections:

\begin{enumerate}
    \item \textbf{Header:} Preset management, global mix, and lookahead controls.
    \item \textbf{Sidebar (Left):} Envelope List. Manage, add, and assign envelopes to MIDI notes.
    \item \textbf{Main Grid (Center):} The Envelope Editor and Waveform Visualizer.
    \item \textbf{Controls (Bottom):} Envelope-specific parameters (Rate, Depth, Smoothness).
    \item \textbf{Metering (Right):} High-resolution input, output, and reduction meters.
\end{enumerate}

\section{Navigation}
\begin{itemize}
    \item \textbf{Left Sidebar:} Click an envelope row to select it for editing.
    \item \textbf{Gear Icon:} Opens the Settings and Theme Manager.
    \item \textbf{Undo/Redo:} Located in the header for quick history navigation.
\end{itemize}
