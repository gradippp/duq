\chapter{Envelope Presets}
\label{ch:envelope_presets}

Envelope presets allow you to build a library of your favorite ducking shapes (e.g., "Short Punch", "Slow Fade", "Sidechain Pump") and reuse them across different projects.

\section{Managing Shapes}
\begin{itemize}
    \item \textbf{Export Shape:} Right-click an envelope in the sidebar and select "Export Shape" to save it as a \texttt{.duq.env} file.
    \item \textbf{Import Shape:} Use the "+" button in the sidebar and select "Import from File" to load a previously saved shape.
\end{itemize}

\section{Independent Loading}
When you load an envelope preset, it replaces only the shape of the currently selected envelope. It does \textbf{not} change your global settings or other envelopes in the list.
