\chapter{Settings Menu}
\label{ch:settings_menu}

Access the settings menu by clicking the gear icon in the header.

\section{General Settings}
\begin{itemize}
    \item \textbf{Waveform Quality:} Choose between Low, Medium, and High. Low quality uses fewer CPU cycles for rendering.
    \item \textbf{Tooltips:} Enable or disable the descriptive tooltips that appear when hovering over controls.
    \item \textbf{Show Source/Sidechain:} Toggle the visibility of the unprocessed audio in the visualizer.
\end{itemize}

\section{Workflow Page}
The workflow page allows you to customize the plugin's behavior to match your editing style:
\begin{itemize}
    \item \textbf{Undo Limit:} Set how many steps are stored in the undo history (default: 200).
    \item \textbf{Default Tension/Curve:} Define the starting state for new segments created in the editor.
    \item \textbf{Default Envelope:} Select a shape to be used whenever a new envelope is added.
\end{itemize}
