\chapter{DAW Compatibility}
\label{ch:daw_compatibility}

Duq is compatible with any modern DAW that supports VST3 or AU plugin formats and MIDI routing to audio tracks.

\section{Supported Formats}
\begin{itemize}
    \item \textbf{VST3 (64-bit):} Compatible with Ableton Live, FL Studio, Cubase, Studio One, Reaper, and more.
    \item \textbf{AU (Audio Unit):} Optimized for Logic Pro and Ableton Live on macOS.
\end{itemize}

\section{System Requirements}
\begin{itemize}
    \item \textbf{Windows:} Windows 10 or later (64-bit).
    \item \textbf{macOS:} macOS 10.13 or later (Intel or Apple Silicon).
    \item \textbf{DAW:} A host capable of routing MIDI data to an audio effect plugin.
\end{itemize}
