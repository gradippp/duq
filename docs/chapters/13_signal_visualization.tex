\chapter{Signal Visualization}
\label{ch:signal_visualization}

Duq provides a real-time waveform visualizer behind the envelope grid to help you align your ducking shapes with the audio.

\section{Visualizer Layers}
\begin{itemize}
    \item \textbf{Source Signal (White/Light):} The incoming unprocessed audio.
    \item \textbf{Sidechain Signal (Dimmed):} If a sidechain input is routed to the plugin (DAW dependent), it is shown for timing reference.
    \item \textbf{Post-Processed Signal (Colored):} The result of the volume ducking.
\end{itemize}

\section{Quality Settings}
The visualizer resolution can be adjusted in the Settings menu (Low, Medium, High). Higher quality settings provide smoother waveforms but increase CPU usage.
