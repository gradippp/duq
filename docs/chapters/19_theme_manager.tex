\chapter{Theme Manager}
\label{ch:theme_manager}

\section{Experimental Status}
\textbf{WARNING:} The Theme Manager is currently an \textbf{experimental feature}. 
\begin{itemize}
    \item Themes created in the current version may not be fully compatible with future updates.
    \item The internal theme file format (\texttt{.duq.theme}) is subject to change.
    \item Use this feature with the understanding that it is for evaluation and customization purposes only.
\end{itemize}

\section{Customization}
The Theme Manager allows you to edit every color in the Duq interface, including:
\begin{itemize}
    \item Background and border colors.
    \item Accent and selection colors.
    \item Waveform and grid colors.
    \item Knob and slider aesthetics.
\end{itemize}

\section{Import/Export}
You can export your custom themes to share with other users or import themes from the community. Use the "Import" and "Export" buttons in the Theme section of the Settings menu.
