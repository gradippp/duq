\chapter{Project Presets}
\label{ch:project_presets}

Project presets are intended to save the entire state of a Duq instance for a specific track or song.

\section{Saving and Loading}
\begin{itemize}
    \item \textbf{Save:} Click the "Save" icon in the header. Enter a name to save the current state to the \texttt{Presets} folder.
    \item \textbf{Load:} Click the preset name in the header to open the browser.
\end{itemize}

\section{What is Saved?}
A project preset includes:
\begin{itemize}
    \item Every envelope in the sidebar (points, curves, tension).
    \item The MIDI trigger note for each envelope.
    \item The Rate, Depth, and Smoothness for each envelope.
    \item Global Mix and Lookahead values.
    \item The current theme selection.
\end{itemize}
