# Duq Factory Content Installation

Thank you for downloading the Duq Factory Content pack.

To use these themes and envelopes, please copy them into the following directories on your system:

## Windows
1. Open File Explorer.
2. Copy the contents of the `themes` folder to:
   `%APPDATA%\Duq\Themes`
3. Copy the contents of the `envelopes` folder to:
   `%APPDATA%\Duq\Presets`

## macOS
1. Open Finder.
2. Press `Cmd + Shift + G` and paste:
   `~/Library/Application Support/Duq/`
3. Copy the `themes` and `envelopes` files into their respective subfolders.

## Linux
1. Copy the files to:
   `~/.config/Duq/Themes` and `~/.config/Duq/Presets`
